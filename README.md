# Penjelasan

Pada kode ini, saya membuat beberapa topic dan service yaitu :  
- publisher_ : untuk menggerakan turtle  
- pose_sub_ : untuk mendapatkan posisi turtle  
- teleport_client_ : untuk menggunakan service teleport_absolute  
- set_pen_client_ : untuk menggunakan service set_pen

lalu saya membuat beberapa method yaitu :  
- move() untuk menggerakan turtle ke arah sekarang (menggambar garis lurus)
- stop() untuk menghentikan gerakan turtle
- draw_circle() untuk menggambar lingkaran
- draw_point() untuk menggambar sebuah titik pada koordinat tertentu
- set_pen() untuk mengatur kondisi pen
- teleport() untuk memindahkan posisi turtle secara instan

Pada main, saya membuat sebuah excutor agar variable x_now, y_now, dan theta_now selalu diupdate.  
saya juga menentukan posisi awal menggambar yaitu st_x dan st_y.   

saya membagi proses menggambar menjadi empat yaitu wheel, body, shell, dan arm
